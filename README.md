# SlapX – Funny Sound Prank App Website

>A modern, SEO-optimized, and production-ready React website for the SlapX mobile app.

---

## 🚀 Features
- Built with **React + Vite + Tailwind CSS**
- React Router DOM for routing
- Fully responsive, modern UI
- SEO meta tags, Open Graph, Twitter Card
- Lazy loading for images
- Accessibility and performance best practices
- Ready for Vercel deployment

---

## 🛠️ Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run locally
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```

### 4. Preview production build
```bash
npm run preview
```

---

## 🌐 Deployment (Vercel)
1. Push your code to **GitHub**.
2. Go to [vercel.com](https://vercel.com), import your repo, and follow the prompts (Vite is auto-detected).
3. Or, deploy via CLI:
   ```bash
   npx vercel
   ```

### GitHub Integration
- Connect your repo to Vercel for automatic deployments on push.
- Configure environment variables in the Vercel dashboard if needed.
